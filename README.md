# Тренеровочный Планер

## Описание
Тренеровочный планер - это приложение для планирования и оптимизации тренировок игроков в футбол. Приложение помогает тренерам эффективно распределять тренировки, чтобы развивать навыки игроков сбалансированно и избежать чрезмерного развития отдельных навыков.

## Особенности
- Создание и управление профилями игроков
- Автоматическая генерация планов тренировок
- Балансировка развития навыков
- Визуализация текущих навыков игрока
- Инструменты для редактирования навыков
- Поддержка светлой/темной темы

## Установка

1. Клонируйте репозиторий
2. Установите зависимости: `pip install -r requirements.txt`
3. Запустите сервер: `python -m web.app`

## Архитектура
- **Frontend**: HTML/CSS/JavaScript с использованием шаблонов Jinja2
- **Backend**: Python Flask приложение
- **Хранение данных**: JSON файлы

## Структура проекта
```
/workspace/
├── config/           # Конфигурационные файлы (позиции, навыки, тренировки)
├── domain/          # Бизнес-логика (игроки, планировщик тренировок)
├── storage/         # Репозитории для хранения данных
├── web/             # Web-интерфейс (Flask приложение)
├── docs/            # Документация
└── tests/           # Тесты
```

## Использование
1. Создайте нового игрока через интерфейс
2. Настройте начальные значения навыков
3. Сгенерируйте план тренировок
4. Примените рекомендованные тренировки
