# Функционал принятия тренировок

## Описание

В системе реализован функционал принятия тренировок, который позволяет:
- Применить отдельную тренировку к игроку (кнопка "Принять тренировку" на каждой карточке)
- Применить все тренировки из плана (кнопка "Принять все тренировки")
- Каждая тренировка прибавляет +1 к характеристикам, которые она качает
- Если тренировка встречается несколько раз (агрегирована), то применяется столько раз, сколько указано в плане

## Архитектура

### Backend
- **domain/player.py**: Метод `apply_training(training_skills, gain=1)` увеличивает указанные навыки на заданную величину
- **web/app.py**: 
  - `/players/<player_id>/accept_training` - маршрут для принятия отдельной тренировки
  - `/players/<player_id>/accept_all_trainings` - маршрут для принятия всех тренировок
- **config/trainings.py**: Справочник всех тренировок с указанием качаемых навыков

### Frontend
- **web/templates/player_detail.html**: Кнопки и JavaScript-функции для принятия тренировок
- **web/templates/plan.html**: Формы для отправки тренировок (альтернативный способ)
- **web/templates/plan_only.html**: Частичный шаблон для динамического обновления плана

## Пример использования

```python
from domain.player import Player

# Создаем игрока
player = Player(name="Test Player", positions=["ST"], skills={"dribbling": 10, ...})

# Применяем тренировку
training_skills = ["dribbling", "finishing", "tackling"]
player.apply_training(training_skills, gain=1)  # +1 к каждому навыку
```

## Особенности реализации

- Прирост ограничен максимальным значением (100)
- При применении тренировки учитываются только те навыки, которые есть у игрока
- Каждая тренировка может качать несколько навыков одновременно
- Количество повторений тренировки в плане учитывается при применении (агрегация)
