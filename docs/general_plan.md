# План реализации приложения помощника прокачки игроков (обновлённый)

## 1. Цель проекта

Создать веб-приложение (Python backend + браузерный интерфейс), которое:

- хранит данные о 11 игроках
- учитывает позиции и «белые / серые» навыки
- автоматически рекомендует тренировки
- минимизирует прокачку серых навыков
- формирует **оптимальные тренировочные циклы** для выравнивания белых навыков
- работает локально и открывается с телефона

Проект рассчитан **для личного использования**, без многопользовательского режима.

## 3. Базовые сущности (Domain Model)

### 3.1 Навык (Skill)
- `id`
- `name`
- Всего: **15 навыков** (фиксированный список)

### 3.2 Позиция (Position)
- `id`
- `code` (ST, AMC и т.д.)
- `white_skills: set[skill_id]`
- Белые навыки задаются один раз и используются для всех игроков

### 3.3 Игрок (Player)
- `id`
- `name`
- `positions: list[position_id]` (1–3 позиции)
- `skills: dict[skill_id, value]`
- Вычисляемые:
  - `white_skills` — объединение белых навыков всех позиций
  - `gray_skills` — остальные навыки
  - `weakest_white_skills(N)` — топ N слабых белых навыков

### 3.4 Тренировка (Training)
- `id`
- `name` — на русском
- `type` — defence / attack / possession / physical
- `affected_skills: set[skill_id]`

## 4. Механики и правила

### 4.1 Деградация навыков
- Раз в месяц:
  - все навыки уменьшаются на **-20**
  - минимальное значение — **1**
- Функция: `apply_monthly_degradation(player)`

### 4.2 Приоритет прокачки
- Выбираем **N самых слабых белых навыков** (настраиваемое N)
- Сортировка по возрастанию

---

## 5. Алгоритм подбора тренировок

### 5.1 Цель
- Сбалансировать белые навыки игрока
- Минимизировать прокачку серых навыков

### 5.2 Логика

1. Вычисляем **отставание каждого белого навыка** от максимального среди белых
2. На каждом шаге цикла:
   - Выбираем тренировку, которая **максимально прокачивает самые слабые белые навыки**
   - Минимизируем затрагивание серых навыков
3. Обновляем значения белых навыков (симуляция прироста)
4. Повторяем до:
   - достижения равного уровня всех белых навыков
   - или достижения лимита тренировок в цикле

### 5.3 Формирование цикла
- Один цикл = 6 тренировок (можно повторять)
- Результат: список тренировок с указанием количества повторений для балансировки белых навыков

## 6. Backend API

- `GET /players`
- `POST /players`
- `PUT /players/{id}`
- `POST /players/{id}/degrade`
- `GET /players/{id}/recommendations?top_n=N&penalty=P`  
  Возвращает **рекомендованный тренировочный цикл** с балансировкой белых навыков
