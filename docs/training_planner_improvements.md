# Улучшения алгоритма планирования тренировок

## Проблемы старого алгоритма

1. **Недостаточная точность симуляции** - просто добавлял фиксированное значение к навыкам
2. **Проблема с балансировкой** - не учитывал разницу между минимальным и максимальным уровнем белых навыков
3. **Отсутствие lookahead** - делал локально оптимальный выбор без прогнозирования будущего

## Внесенные улучшения

### 1. Введение системы симуляции

- Создана система симуляции, которая моделирует влияние тренировок на навыки
- Учитываются максимальные значения навыков (не более 400)
- Реализован метод `_apply_training` для симуляции эффекта тренировки

### 2. Улучшенная логика выбора тренировок

- Вместо простого поиска тренировок, влияющих на 2+ белых навыка, теперь:
  - Сравниваются потенциальные улучшения равномерности распределения навыков
  - Учитывается текущая разница между min и max белыми навыками
  - Приоритет отдается тренировкам, которые уменьшают эту разницу

### 3. Механизм оценки эффективности тренировки

Метод `_calculate_improvement` оценивает:
- Улучшение равномерности (gap_improvement): разница между старой и новой разницей max-min
- Повышение среднего уровня белых навыков (avg_improvement)
- Веса этих факторов можно настраивать

### 4. Система штрафов

- Введен штраф за задействование серых навыков
- Уменьшает приоритет тренировок, которые влияют на ненужные навыки

### 5. Новая структура данных

- Введена dataclass `TrainingPlanItem` для представления элемента плана
- Более понятная структура: `training_id`, `name`, `repeats`

## Преимущества нового алгоритма

1. **Более точная симуляция** - учитывает реальное изменение распределения навыков
2. **Фокус на равномерность** - стремится уменьшить разброс белых навыков
3. **Прогнозирование** - оценивает влияние тренировки до её применения
4. **Гибкая настройка** - веса факторов могут быть легко изменены
5. **Лучшая интерпретация результата** - понятная структура плана тренировок

## Пример работы

На тестовом игроке с позициями ['AMC', 'MC', 'DMC'] и низкими навыками:
- Агрессивность: 54
- Сила: 54
- Опека: 55

Алгоритм предлагает план, который:
- Сначала улучшает самые слабые навыки
- Постепенно выравнивает распределение белых навыков
- Минимизирует прокачку серых навыков
