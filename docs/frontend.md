# Документация Frontend части

## Структура
Frontend реализован с использованием HTML, CSS и JavaScript с шаблонами Jinja2.

### Файлы
- `templates/base.html` - базовый шаблон со стилями и структурой страниц
- `templates/player_detail.html` - главная страница с деталями игрока
- `templates/players.html` - список всех игроков
- `templates/player_form.html` - форма создания нового игрока
- `templates/plan_only.html` - шаблон для отображения только плана тренировок

## Стилизация
Используется темная тема по умолчанию с возможностью легкого изменения через CSS переменные в `base.html`.

### Цветовые переменные
- `--bg-primary`: основной фон (#121212)
- `--bg-secondary`: фон контейнеров (#1e1e1e)
- `--bg-tertiary`: фон карточек (#2d2d2d)
- `--text-primary`: основной текст (#e0e0e0)
- `--accent-blue`, `--accent-red`, `--accent-green`, `--accent-yellow`: акцентные цвета

## JavaScript функциональность
### Обновление навыков
- `changeSkillValue()` - изменение значения навыка с кнопок +/- 
- `saveSkillAndRefreshPlan()` - сохранение изменений и обновление плана
- `refreshPlan()` - пересчет плана тренировок
- `applyToAll()` - применение изменения ко всем навыкам

### Применение тренировок
- `acceptTraining()` - принятие конкретной тренировки
- `acceptAllTrainings()` - принятие всех тренировок
- Анимации подсветки навыков при применении тренировок

## Компоненты
### Карточки навыков
- Отображение всех навыков в порядке из конфига
- Различие между белыми (основными) и серыми (вспомогательными) навыками
- Кнопки быстрого изменения значений (+/- 1, 5, 10)

### План тренировок
- Отображение рекомендованных тренировок
- Категоризация по типам (атака, защита, владение, физика)
- Возможность принятия отдельных или всех тренировок

### Выделение слабых/сильных навыков
- Отображение 3 самых слабых и 3 самых сильных белых навыков
- Цветовое кодирование (красный для слабых, зеленый для сильных)
